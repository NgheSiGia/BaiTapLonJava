# VPHONE - Ung dung quan ly ban dien thoai bang Java + Oracle Database

Bai tap lon mon Cong nghe Java, dung chung cho mon He quan tri CSDL Oracle. Co 2 giao dien:
**console** va **web (chay tren Chrome)**. Du lieu doc len cac `ArrayList` de xu ly (tim kiem, sap xep, thong ke)
va **moi thay doi duoc ghi xuong Oracle Database** qua JDBC.

## Yeu cau
- JDK 11 tro len (khuyen dung 17 hoac 21).
- **Oracle AI Database 26ai Free** da cai (nhu slide huong dan), 2 service phai o trang thai Running:
  `OracleServiceFREE` va `OracleOraDB..._TNSListener`.
- File driver **ojdbc17.jar hoac ojdbc11.jar** (chi can 1 file) dat trong thu muc `lib/` (xem `lib/HUONG_DAN_DRIVER.txt`; file co san trong thu muc cai Oracle).

## Cai dat lan dau (lam 1 lan)
1. **Chep driver**: copy `ojdbc17.jar` (hoac `ojdbc11.jar`) vao thu muc `lib/` cua project.
2. **Tao user VPHONE** trong Oracle (bang quyen SYSDBA). Mo Command Prompt tai thu muc `vphone`:
   ```
   sqlplus / as sysdba
   SQL> @sql/01_tao_user_oracle.sql
   SQL> exit
   ```
   (Hoac mo SQL Developer, ket noi SYS as SYSDBA, mo file `sql/01_tao_user_oracle.sql` va chay.)
   Script tao user `vphone` / mat khau `vphone123` trong PDB `FREEPDB1`. Neu PDB cua ban ten khac thi sua trong script va `db.properties`.
3. **Kiem tra ket noi**: chay `java -cp "out;lib/*" Main --check-db` - in ra phien ban Oracle, driver, schema va 7 bang da co hay chua.
4. **Chay chuong trinh**: lan dau ung dung tu tao 7 bang va nap du lieu mau.
   (Muon tao thu cong: ket noi bang user VPHONE roi chay `sql/02_tao_bang_oracle.sql` va `sql/03_du_lieu_mau_oracle.sql`.)

## Cach chay
### Trong VS Code
1. Cai JDK va extension **Extension Pack for Java**; mo thu muc `vphone` (thu muc chua `src`, `lib`, `.vscode`).
2. *Run and Debug* (Ctrl+Shift+D) -> chon cau hinh roi bam Run:
   - `VPHONE Web (mo bang Chrome)` - giao dien web, mo `http://localhost:8080`;
   - `VPHONE (Oracle)` - giao dien console;
   - `VPHONE demo tu dong (bo nho)` - kich ban tu dong, khong dung CSDL;
   - `VPHONE kiem tra ket noi Oracle` - in thong tin ket noi (`--check-db`);
   - `VPHONE reset CSDL` - xoa 7 bang va tao lai.
### Bang dong lenh
```
javac -encoding UTF-8 -cp "lib/*" -d out src/*.java
java -cp "out;lib/*" Web               # giao dien web (Linux/macOS dung dau : thay cho ;)
java -cp "out;lib/*" Main              # giao dien console
java -cp "out;lib/*" Main --demo       # kich ban tu dong (bo nho)
java -cp "out;lib/*" Main --check-db   # kiem tra ket noi Oracle (phien ban, driver, schema, bang)
java -cp "out;lib/*" Main --reset-db   # xoa va tao lai cac bang
```
Hoac bam doi `run.bat` (Windows) / `sh run.sh`; them `web`, `demo`, `check` hoac `reset` sau ten script.

## Co so du lieu Oracle
- Cau hinh ket noi trong `db.properties` (host, cong 1521, service `freepdb1`, user, mat khau).
- Chuoi ket noi: `jdbc:oracle:thin:@//localhost:1521/freepdb1`.
- 7 bang: `nguoi_dung`, `san_pham`, `nha_cung_cap`, `don_hang`, `chi_tiet_don_hang`, `phieu_nhap`, `chi_tiet_phieu_nhap`
  (khoa chinh, khoa ngoai, `CHECK`, cot tu tang `GENERATED BY DEFAULT AS IDENTITY`).
- Kieu du lieu Oracle: `VARCHAR2(n CHAR)`, `NUMBER`, `DATE`. Chuoi rong duoc Oracle xem la `NULL` nen cac cot tuy chon cho phep `NULL`.
- Khong ket noi duoc Oracle: chuong trinh in loi kem goi y va **tu chuyen sang che do bo nho** (du lieu mat khi tat).
- Xem du lieu: SQL Developer -> ket noi user `vphone`, mo cac bang; hoac `sqlplus vphone/vphone123@localhost:1521/freepdb1`.

### Loi thuong gap
| Loi | Nguyen nhan | Cach khac phuc |
|---|---|---|
| `No suitable driver` | Thieu ojdbc11.jar trong `lib/` | Chep driver vao `lib/` |
| ORA-01017 | Sai user/mat khau hoac chua tao user | Chay `sql/01_tao_user_oracle.sql` bang SYSDBA; kiem tra `db.properties` |
| ORA-28000 | Tai khoan bi khoa | `ALTER USER vphone ACCOUNT UNLOCK;` |
| ORA-12541 TNS:no listener | Service TNSListener chua chay | Start service nay, doi khoang 1 phut |
| ORA-12514 | Sai service name hoac instance chua startup | Kiem tra `db.service` (`show pdbs;`), start OracleServiceFREE |
| ORA-12560 | Thieu Service Name / ORACLE_SID | Kiem tra lai `db.properties` |
| ORA-01882 timezone region not found | Mui gio he thong khong nhan duoc | Them tham so JVM `-Doracle.jdbc.timezoneAsRegion=false` |
| ORA-01950 no privileges on tablespace | User chua co quota | Chay lai script tao user (co `QUOTA UNLIMITED ON users`) |

## Giao dien web (Chrome)
Chay `Web`, mo `http://localhost:8080`. Khach hang: xem/tim/loc/sap xep san pham, gio hang, dat hang, huy don, lich su.
Quan tri vien: them/sua/xoa san pham, xu ly don, nha cung cap, lap phieu nhap, thong ke, nguoi dung.
May chu chi nhan ket noi tu chinh may ban (`127.0.0.1`). Loi hien thi tieng Viet co dau (`Vi.java`).

## Kien truc
```
Main / Demo / Web (+ web/*.html, js, css)  ->  *Manager (ArrayList + nghiep vu)  ->  *DAO (JDBC)  ->  Oracle
```
- Ghi CSDL truoc, cap nhat ArrayList sau. Dat hang / huy don / lap phieu nhap dung **giao dich** (commit/rollback).
- Loi CSDL duoc bao bang `DataAccessException`; xoa san pham da co trong don hang bi khoa ngoai chan (ORA-02292).

## Luu y: tach rieng voi bo script cua mon Oracle/APEX
Bo script `VPHONE_Oracle_SQL.zip` (mon Oracle) cung tao cac bang `san_pham`, `don_hang`... va co trigger tu tru kho.
De tranh chong cheo, **khong chay hai bo vao cung mot schema**: mon Java dung user `vphone` theo huong dan nay; mon Oracle chay tren APEX
hoac tren mot user khac (vi du `vphone_ql`).

## Kiem thu
Cau lenh tao bang (DDL) nay cung duoc dung trong bo script SQL da duoc kiem chung tren Oracle AI Database 26ai Free that. Logic chuong trinh va cu phap SQL da duoc chay thu tren **H2 o che do tuong thich Oracle** (`MODE=Oracle`): tao bang, dat hang, huy don,
nhap hang, khoa ngoai, rollback giao dich, giao dien web tren Chromium. **Chua chay tren Oracle Database that**
(may phat trien khong cai duoc Oracle) - hay chay thu tren may ban theo cac buoc tren va bao lai neu co loi.
